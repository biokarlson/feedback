# feedback-bot

Telegram-бот обратной связи на aiogram 3.

Пользователи пишут боту в личку, сообщения пересылаются в рабочий чат. Ответ реплаем на пересланное сообщение приходит написавшему пользователю.

## Запуск

1. Создайте бота в [@BotFather](https://t.me/BotFather) и добавьте его в рабочий чат.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `ADMIN_CHAT_ID` (id чата вида `-100...`).
4. Запустите:
   ```bash
   python bot.py
   ```

## Как это работает

- Любое сообщение в личку боту пересылается в чат.
- Соответствие «сообщение в чате → пользователь» хранится в SQLite (`feedback.db`), поэтому ответы работают и после перезапуска.
- Ответ нужно давать реплаем именно на пересланное сообщение. Обычные сообщения в чате бот игнорирует.
